## 功能选择

### ⭐⭐⭐ 新增：倪海厦中医建议生成器

**核心能力**：整合九宫格命理 + 倪海厦经方体系，从六经辨证角度提供个性化中医养生方案。

**报告内容**：
| 章节 | 内容 |
|------|------|
| 基本信息 | 姓名、生辰、年龄、命盘、今日天时 |
| 命理脏腑分析 | 阳缺/阴缺脏腑、阴阳周期状态、生命周期 |
| 六经辨证分析 | 少阴/少阳/阳明/太阴/厥阴/太阳各脏腑分析 |
| 综合养生方案 | 六健康标准自检、日常养生要点、节气养生 |
| 穴位保健 | 各脏腑推荐穴位与按摩方法 |

**使用示例**：
```bash
# 默认蓝馨
python 倪海厦中医建议生成器.py

# 完整参数
python 倪海厦中医建议生成器.py -n "张三" -b "1990/05/20" -g "女" -l "上海"

# 指定时辰
python 倪海厦中医建议生成器.py -n "李四" -b "1985/03/15" -t "午时" -g "男"
```

**参数说明**：
| 参数 | 必须？ | 说明 |
|:----:|--------|------|
| `-n 姓名` | ❌ | 姓名（默认蓝馨） |
| `-b 日期` | ❌ | 出生日期 YYYY/MM/DD（默认1991/08/16） |
| `-g 性别` | ❌ | male/男 或 female/女（默认male） |
| `-l 地点` | ❌ | 出生地点（城市名，不填默认北京时间） |
| `-t 时辰` | ❌ | 时辰（不填则自动计算真太阳时） |

## 四种情况支持

| 情况 | 魂数 | 构成 |
|------|------|------|
| 普通人 | 2魂 | 阳格魂 + 阴格魂 |
| 普通+身份证触发 | 4魂 | 阳格魂 + 阴格魂 + 身份证阳格魂 + 身份证阴格魂 |
| 子时出生 | 4魂 | 阳A + 阳B + 阴A + 阴B |
| 子时+身份证触发 | 最多8魂 | 四魂 + 身份证四魂 |

### 身份证系统触发条件
- 身份证上的生日（阳历）≠ 真实阳历生日
- 判断标志：右手大拇指横纹比左手多一根
- 影响：普通人2魂→4魂，子时4魂→最多8魂

## 两大体系说明

### 1. 慈海九宫格（卢先生道医体系）

- **来源**：IMA"卢先生经典语录资料包"
- **数字体系**：1=肺，2=大肠，3=心，4=肝，5=胆，6=肾，7=胃，8=脾，9=膀胱，0=小肠
- **核心**：阳格、阴格、阳缺、阴缺、半补、缺格修正
- **阴阳格主导**：根据当前阶段自动判断主导缺格

### 2. 阴阳格周期（卢先生生命周期理论）

- **来源**：IMA"九宫格阴阳格切换.docx"
- **男性周期**：阳格11.9年 → 换魂2.3年 → 阴格9.7年（固定）
- **女性周期**：阳格9.7年 → 换魂2.3年 → 阴格11.9年（受生育影响）
- **食疗主导**：
  - 阳格期：以阳缺为主，阴缺轻补
  - 阴格期：以阴缺为主，阳缺轻补
  - 换魂期：阴阳同补，重点调理

## 阴阳格周期表

### 男性（固定周期制）

| 阶段 | 年龄区间（岁） |
|------|---------------|
| 阳格1 | 0 ~ 11.9 |
| 换魂1 | 11.9 ~ 14.2 |
| 阴格1 | 14.2 ~ 23.9 |
| 阳格2 | 23.9 ~ 35.8 |
| 换魂2 | 35.8 ~ 38.1 |
| 阴格2 | 38.1 ~ 47.8 |

### 女性（生育影响制）

| 阶段 | 年龄区间（岁） |
|------|---------------|
| 阳格1 | 0 ~ 9.7 |
| 换魂1 | 9.7 ~ 12 |
| 阴格1 | 12 ~ 23.9 |
| 阳格2 | 23.9 ~ 33.6 |
| 换魂2 | 33.6 ~ 35.9 |
| 阴格2 | 35.9 ~ 47.8 |

## 数字阴阳属性（卢先生体系）

| 属性 | 数字 | 对应脏腑 |
|------|------|----------|
| **阴（五脏）** | 1、3、4、6、8 | 肺、心、肝、肾、脾 |
| **阳（六腑）** | 2、5、7、9、0 | 大肠、胆、胃、膀胱、小肠 |

**注意**：0 = 小肠（阳），9 = 膀胱（阳）
