# 完整综合命理报告生成器 · 使用说明

## 快速开始

### 基本命令
```bash
python 完整综合命理报告v3.9.py "生日" "时辰" "性别"
```

### 参数说明

| 参数 | 必须？ | 说明 | 示例 |
|:----:|--------|------|------|
| `生日` | ✅ | 阳历生日，格式 YYYY/MM/DD | `"1991/08/16"` |
| `时辰` | ❌ | 出生时辰（默认巳时） | `"巳时"` |
| `性别` | ❌ | male/男 或 female/女（默认male） | `"男"` |

### 示例命令
```bash
# 男性命盘
python 完整综合命理报告v3.9.py "1991/08/16" "巳时" "男"

# 女性命盘
python 完整综合命理报告v3.9.py "1991/08/16" "巳时" "女"

# 使用默认参数（1991/08/16 巳时 男）
python 完整综合命理报告v3.9.py
```

## 四种情况

### 1. 普通人（2魂）
```bash
python 完整综合命理报告v3.9.py "1991/08/16" "巳时" "男"
```
- 阳格魂 + 阴格魂
- 根据当前阶段自动判断主导缺格

### 2. 普通人 + 身份证触发（4魂）
```bash
python 完整综合命理报告v3.9.py "1991/08/16" "巳时" "男"
# 身份证生日 ≠ 真实生日时触发
```
- 身份证生日 ≠ 真实生日时触发
- 父母接引系统（真实生日） + 猎户接入系统（身份证生日）
- 判断标志：右手大拇指横纹比左手多一根

### 3. 子时出生（4魂）
```bash
python 完整综合命理报告v3.9.py "1992/03/15" "子时" "男"
```
- 阳A + 阳B + 阴A + 阴B
- 每日/随时切换，性格情绪可能波动大
- 表现：前一秒答应的事后一秒反悔

### 4. 子时 + 身份证触发（最多8魂）
```bash
python 完整综合命理报告v3.9.py "1992/03/15" "子时" "男"
# 身份证生日 ≠ 真实生日
```
- 最多8个灵魂同时抢方向盘
- 修行难度急剧增加

## 身份证系统说明

### 触发条件
身份证上的生日（阳历）≠ 真实阳历生日

### 判断标志
- 右手大拇指横纹比左手多一根
- 人生感受：长期感到"课题巨大"、"人生不受控"、"总有莫名阻碍"

### 影响
- 普通人：2魂 → 4魂
- 子时出生：4魂 → 最多8魂
- 修行难度急剧增加

### 解决方案
- 家排（家庭系统排列）
- 个人深度清理
- 需授权者操作（如蔡老师：格为37101且已修通）

## 核心原则

### 三体系数字独立
- **慈海九宫格数字**：1=肺，2=大肠，3=心...（卢先生道医体系）
- **紫微斗数数字**：用于宫位编号（1-12宫），与脏腑无关
- **奇门遁甲数字**：用于方位（1-9宫），含义不同

### 桥接方式
三者通过 **天干 → 五行 → 脏腑** 间接关联，不可直接数字对等。
