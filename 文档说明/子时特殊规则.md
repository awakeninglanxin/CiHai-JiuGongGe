# 子时出生者阴阳格特殊规则
# 来源：卢先生道医体系文档
# 记录时间：2026-03-31

## 核心规则

### 一、子时出生者 = 四魂系统

普通人：2套灵魂（阳格魂 + 阴格魂）
子时出生者：4套灵魂

| 魂 | 原名 | 显示名 | 说明 |
|----|------|--------|------|
| 阳格1 | 前子时阳格 | 阳A | 当天格（阳格大周期主导） |
| 阳格2 | 后子时阳格 | 阳B | 调整格（阳格大周期辅助） |
| 阴格1 | 前子时阴格 | 阴A | 当天格（阴格大周期主导） |
| 阴格2 | 后子时阴格 | 阴B | 调整格（阴格大周期辅助） |

### 二、双轨切换机制

**第一层（长周期）**：遵循普通阴阳格大周期
- 男性：阳格11.9年 → 换魂2.3年 → 阴格9.7年
- 女性：阳格9.7年 → 换魂2.3年 → 阴格11.9年
- 阳格大周期 → 阳A + 阳B 共同负责
- 阴格大周期 → 阴A + 阴B 共同负责

**第二层（短周期）**：同一大周期内高频切换
- 阳A 和 阳B 一天一换，甚至随时抢方向盘
- 表现：前一秒答应的事后一秒反悔；白天大方晚上计较

### 三、前子时 vs 后子时

| 时间 | 归属 | 日期处理 |
|------|------|----------|
| 23:00-00:00 | 前子时 | 用当天日期 |
| 00:00-01:00 | 后子时 | 日期 +1 天 |

计算四套格时，需对日期进行加减一天操作。

### 四、身份证系统触发（叠加情况）

**触发条件**：身份证上的生日（阳历）≠ 真实阳历生日

> ⚠️ 注意：身份证日期为**阳历**，若用户提供农历需先转换为阳历再计算

**四种情况汇总**：

| 情况 | 魂数 | 构成 |
|------|------|------|
| 普通人 | 2魂 | 阳格魂 + 阴格魂 |
| 普通人 + 身份证触发 | 4魂 | 阳格魂 + 阴格魂 + 身份证阳格魂 + 身份证阴格魂 |
| 子时出生 | 4魂 | 阳A + 阳B + 阴A + 阴B |
| 子时出生 + 身份证触发 | 最多8魂 | 阳A + 阳B + 阴A + 阴B + 身份证阳A + 身份证阳B + 身份证阴A + 身份证阴B |

**触发后影响**：
- 普通人：2魂 → 4魂（父母接引系统 + 猎户接入系统各一套）
- 子时出生者：4魂 → 最多 8魂
- 阳格大周期时：4个魂（阳A, 阳B, 身份证阳A, 身份证阳B）同时抢方向盘

**判断标志**：
- 右手大拇指横纹比左手多一根 = 触发标志
- 纹路越深越复杂 = 影响越深

**影响维度**：
1. 修行难度急剧增加（需修通两套独立课题）
2. 人生课题巨大（祖先未完成诉求 / 猎户编程）
3. 内在混乱（换魂不规律，身不由己）
4. 能量消耗加倍（两套系统互相冲突）

**解决方案**：
- 家排（家庭系统排列）
- 个人深度清理（需被授权者操作，如蔡老师：格为37101且已修通）
- 效果：降低修行难度，但无法取消修行课题

### 五、两套系统来源

| 系统 | 来源 | 触发方式 |
|------|------|----------|
| 父母接引系统 | 真实出生日期 | 出生即激活 |
| 猎户接入系统 | 错误身份证日期 | 需被触发才激活 |

### 六、程序处理规则

当用户时辰为子时时，程序应：
1. 询问：是前子时（23:00-00:00）还是后子时（00:00-01:00）？
2. 询问：身份证上的生日是否与真实阳历生日一致？
3. 若不一致：列出更多情况（最多8魂分析）
4. 计算四套格：阳A、阳B、阴A、阴B

### 七、蓝馨说明

蓝馨出生时辰：巳时（9-11点）
→ 非子时出生，适用普通两魂系统
→ 阳格1358 / 阴格347，正常双魂规则
