# 九宫格查询与信息说明

## 文件夹结构

```
九宫格查询与信息说明/
├── nine_palace_query.py    # 主查询工具（运行此文件）
```

## 运行方法

### 方式一：直接运行
```
python nine_palace_query.py
```

### 方式二：命令行传参
```
python nine_palace_query.py 1991/12/24 -s 卯时
```

## 功能说明

### 基础查询
输入阳历生日和时辰，自动计算并显示：
- 阳格 / 阴格
- 阳缺 / 阴缺
- 半补（时辰对应五行→数字映射）
- 灵魂积分（星级 + 名称 + 层级）

### 详细解读（自动追加）
根据阴阳双格组合，自动从字典中查找并追加：
- **组合名称**：如"唐僧与牛魔王"
- **单格身份**：阳格和阴格各代表什么角色/神明
- **核心特质**：该组合的特点、优势和挑战
- **跌落路径**：如果该格有对应跌落路径（如28101→...→325）
- **修行总纲**：卢先生对该组合的核心修行提示

### 阴阳同格特殊说明
当阳格=阴格时（如347/347、369/369），自动识别为"阴阳同格（纯格）"，并额外说明：
- 能量纯粹性优势（天赋高度聚焦）
- 课题高度集中的挑战
- 缺数补足建议

## 时辰→五行→半补对照

| 时辰 | 五行 | 半补 |
|------|------|------|
| 申时、酉时 | 金 | 12 |
| 寅时、卯时 | 木 | 45 |
| 亥时、子时 | 水 | 06 |
| 巳时、午时 | 火 | 3 |
| 辰戌丑未时 | 土 | 789 |

注：子时需区分前子时（23:00-00:00，属于下一天）和后子时（00:00-01:00，属于当天）
